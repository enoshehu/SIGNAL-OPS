    04 / Processing rules

    How the numbers
    are produced.

    01

    Download

    GitHub Actions is scheduled every 15 minutes. Each run fetches sources that are due; queued or failed runs can delay publication.

    02

    Retain history

    Analysis keeps 180 days. Original downloads remain available for 30 days for replay and recovery.

    03

    Match

    Plans and changes match by station, stop ID and event type. Weather matches by city and UTC hour.

    04

    Report

    Delay rate uses matched events. Missing, unmatched and unclassified records stay visible and are never counted as on-time or zero.

    Comparison rule

    No matching city-hour, no weather comparison.
